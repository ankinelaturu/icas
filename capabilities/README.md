# Generated Capabilities

This directory is reserved for capability artifacts produced by ICAS discovery/adaptation.

Do not hand-author files here merely to make the demo look complete. The primary example capability committed for submission should be generated by a genuine discovery run and traceable to evidence under `../evidence/`.

A capability is expected to include:

- schema and capability versions;
- capability identity/name/description;
- Vendor + Product target identity;
- discovery/verification metadata;
- typed inputs;
- typed outputs and extraction rules;
- ordered steps with preconditions, action, and postconditions;
- final success conditions.
