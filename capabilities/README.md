# Generated Capabilities

This directory is reserved for capability artifacts produced by ICAS discovery/adaptation. `@icas/capability` (`FileSystemCapabilityRegistry`) is the only writer. Do not glob or edit these files from CLIs.

Do not hand-author files here merely to make the demo look complete. The primary example capability committed for submission should be generated by a genuine discovery run and traceable to evidence under `../evidence/`.

## Layout

```text
capabilities/
  loan-payoff/
    1.0.0.json           # base CapabilityArtifact (Vendor+Product)
    overrides/
      icas-bank.json      # header-only enrollment after first discover
      loki-bank.json      # header-only if compatible, or a declarative patch
```

The effective capability (base + override) is never stored here. See `docs/04-capability-artifact.md`.

A capability is expected to include:

- schema and capability versions;
- capability identity/name/description;
- Vendor + Product target identity;
- discovery/verification metadata;
- typed inputs;
- typed outputs and extraction rules;
- ordered steps with preconditions, action, and postconditions;
- final success conditions.
